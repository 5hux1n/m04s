macOS · BLE 打印驱动

从 Mac，直接打印。

将图片转成热敏点阵，通过蓝牙发送到印先森 M04S。配套本地网页工作台，支持文字排版、图片处理，以及网页和文档导入。

查看安装说明 ↗阅读项目说明 ↗

已有 M04S 黑白 MiniLZO 路径的真机验证。其他批次和新增型号仍需分别测试；实际蓝牙发送目前仅支持 macOS。

项目能做什么

图片与文字

组合文字和图片，调整方向、裁剪、对比度和黑白处理，打印前预览点阵。

本地工作台

在本机网页中处理图片、网页、PDF 和 Word 文档，管理逐页打印队列。

设备与状态

查询设备电量、纸张和温度，设置浓度和走纸，并等待设备完成通知。

开始使用

  1. 准备 macOS、Python 及项目 README 列出的依赖，核对打印机型号和支持范围。
  2. 克隆仓库、安装依赖，先用 --dry-run 生成预览，再连接蓝牙并打印。
  3. 运行 python console/run.py 打开本地工作台；使用前断开手机官方 App。

完整说明、兼容范围与最新状态见 项目 README。问题反馈请前往 GitHub Issues。

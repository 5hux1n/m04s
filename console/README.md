# M04S 本机打印工作台

## 使用

双击工作区根目录的 `start_console.command`，打开 **http://127.0.0.1:8765**。
保持启动服务的终端窗口开启；停止服务可在该窗口按 Ctrl+C。
重复双击会打开现有控制台，不会启动第二个打印服务。

1. 打开 M04S，断开手机官方 App，在网页中点击“连接打印机”。
2. 在“纸面与图像”选择与实际纸卷一致的宽度。
3. 编辑图文，或导入网页／文档；右侧显示实际黑白打印点阵。
4. 检查预览后点击“打印作品”，在“打印记录”查看进度及设备完成通知。

## 功能

| 页面 | 能力 |
| --- | --- |
| 图文编辑器 | 草稿自动保存、打开／新建／删除；文字、图片、分隔线和留白的组合及排序 |
| 文字排版 | 黑体／宋体／等宽、字号、加粗、行距、对齐；横排、从右到左／从左到右竖排、90°／180°／270°、镜像 |
| 图片处理 | 原图、黑白照片、线稿、素描、文字增强；明暗、对比度、效果强度、反色；旋转、宽度、方形／横幅／拖动框选裁剪 |
| 纸面 | 53／80／110 mm 纸卷、固定／自动高度、边距、黑白阈值、照片抖动、预览缩放和 PNG 导出 |
| 网页打印 | 输入公开网页链接，导入可读取的正文和最多 5 张图片，生成可编辑的新草稿 |
| 文档打印 | PDF 保留页面版式，支持页码范围、逐页预览和全部导入页打印；DOCX 导入文字、嵌入图片和表格文字；DOC／TXT 导入文字 |
| 设备状态 | 实际电量、上盖、有纸、温度状态、纸张模式和自动关机时间；刷新、连接／断开、空白走纸 |
| 打印设置 | 淡／中／浓／专用、纸张传感器模式、份数、默认纸宽、自动关机、浓度系数和实验速度值 |
| 打印记录 | 排队、传输、等待设备完成、失败原因、实际提交预览、完成通知记录；取消尚未开始的任务 |

## 长内容预览

桌面窗口中，右侧预览随页面滚动保持可见，高度随窗口调整。
长纸面在预览内部滚动，纸面设置也可以单独滚动。

点击预览标题旁的“浮窗”，可打开与编辑器实时同步的浮动预览。
拖动顶部移动位置，拖动右下角调整大小；“−”收起、“×”关闭。
缩小窗口后浮窗会自动留在可见范围内。
窄屏编辑时可随时使用右下角的“预览浮窗”入口。
浮窗顶部获得键盘焦点后，也支持方向键移动、Shift 加方向键加快移动、Esc 关闭。

## 纸宽与打印限制

纸卷宽度与可打印宽度不同。开发时分析的 M04S 官方配置给出
53／80／110 mm 纸卷、48／72／106 mm 内容宽度，以及 1248 点上限和 300 DPI。
点阵每行按字节对齐，工作台输出如下：

| 纸卷 | 点阵宽度 | 每行字节 | 实际点阵宽度 |
| --- | ---: | ---: | ---: |
| 53 mm | 568 | 71 | 约 48.1 mm |
| 80 mm | 848 | 106 | 约 71.8 mm |
| 110 mm | 1248 | 156 | 约 105.7 mm |
| 53 mm 原有打印宽度 | 592 | 74 | 约 50.1 mm |

原有草稿保留 592 点基线，新作品采用设置中的默认纸宽。
纸宽选择同时改变 Canvas 排版、PNG、LZO 任务头及每行数据，发送到设备时不再统一缩放成 592 点。
80／110 mm 已通过编码、解码、预览和队列检查，尚未使用对应纸卷实测。
此前 592 点基线完成过真实网页打印。新的 568 点模式已完成软件验证，
纸面输出及新宽度模式需要更多真机结果。

单张最大高度 12000 点（约 1016 mm），固定高度不能截断内容；上传图片／文档最大 10 MB。
PDF 每次最多导入 20 页；多页分别提交独立打印任务，按顺序等待设备完成。
网页导入针对可公开读取的正文，登录页面或仅由 JavaScript 动态生成的内容可能无法读取。
DOCX 会重新排版；复杂版式需另存为 PDF 上传。当前不提供 OCR。

速度协议值实机测试没有明显调速效果，因此只保留实验入口。
间隙／黑标模式能设置和回读，对应介质的自动定位仍待实测。
设备断开后状态显示“未知”，不会用旧值伪装在线；任务完成依赖 FF01 `1a 0f 0c`。

## 文件位置

所有运行数据都位于项目根目录内，与项目启动位置无关：

- `console/`：PHP 页面与接口、前端处理、Python 本机桥接和导入模块。
- `storage/console/console.sqlite`：草稿、设备状态、队列和事件。
- `storage/console/uploads/`：上传及导入的图片。
- `storage/console/imports/`：上传的原始文档。
- `storage/console/renders/`：提交打印时的 PNG 快照。
- `storage/console/tmp/`：临时文件。
- `artifacts/console/`：每个任务的 `preview.png`、`printtask.bin`、参数及测试截图。
- `logs/console/`：服务、导入、设备通知及验证日志。
- `storage/console-test/`：独立的软件测试数据，不接入真实打印机。

服务关闭后，复制 `storage/console` 和 `artifacts/console` 可备份草稿及记录。
PHP 服务只监听本机回环地址；写入操作使用页面令牌校验。
图片效果在浏览器本地运行。网页导入仅按输入的链接读取网络内容。

## 运行结构

浏览器图文编辑／预览 → PHP 本机接口与 SQLite 队列 → Python 持续连接的 BLE 驱动 → M04S。

BLE 使用设备 FF03 信用流控和 macOS 的发送就绪回调；没有固定的逐包发送间隔。
保留 15 ms 的控制／点阵边界，以及设备完成通知后的 1 秒收尾。
已确认打印完成后，即使随后状态刷新失败，也不会把已出纸的任务重新标为打印失败。
服务重启不会自动重发上次未确认完成的任务，避免重复出纸。

macOS 的蓝牙执行进程必须由具有蓝牙访问能力的 Terminal 启动。
启动脚本优先使用项目 `.venv/bin/python3`，PHP 从 PATH 查找。
按根目录 README 安装 `console/requirements.txt`，其中包含 PDF 引擎
PyMuPDF、python-docx 和 BeautifulSoup4；liblzo2 通过 Homebrew 安装。
仓库不分发预装的 vendor 二进制依赖。

## 验证记录

- 原驱动 22 个检查：官方任务／原 66 点阵保持一致，多种宽度解压回读、流控、完成通知及状态处理。
- 控制台 9 个检查：页面令牌、非法参数、离线提交、实际预览尺寸、队列取消、导入页码、重启恢复及完成后断连。
- 图片算法检查：空白不生成假边缘、轮廓、文字背景、明暗／对比度、反色、素描和抖动。
- 浏览器检查：四种宽度、五种图片效果、框选裁剪、文字方向、草稿恢复、TXT／DOCX／PDF／网页导入、手机布局。
- PDF 两页批量提交检查：独立队列、页码顺序及取消；此检查使用隔离的模拟在线状态，不连接硬件。
- 提交快照检查：提交后的编辑不会改变已提交的 PNG、纸宽或标题；此检查拦截写入，不修改真实草稿或提交硬件打印。
- 长内容预览检查：页面滚动后右侧保持可见，三种桌面窗口高度自适应；浮窗像素同步、拖动、缩放、收起、键盘操作及窄屏范围约束通过，未连接硬件。

对应日志位于 `logs/console/`，浏览器截图及效果图片位于 `artifacts/console/`。
